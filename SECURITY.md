# Security reports

Do not put credentials, tokens, PINs, VINs, account identifiers, location, raw requests/responses or vehicle-control exploits in public issues.

Once this repository is public, use GitHub **Security → Advisories → Report a vulnerability** for a private report. The maintainer must enable private vulnerability reporting before launch; no private-report URL or email is claimed until that channel exists. If the button is unavailable, do not disclose details publicly: request that a private channel be enabled without including the sensitive details.

Describe impact, affected versions/methods, prerequisites and a synthetic reproduction. Do not operate a real vehicle without its owner's explicit approval of the exact action. Do not send secrets or request captures as evidence. Rotate any exposed credentials through the official service first.

Only the current prerelease is intended to receive fixes during this experimental stage. There is no response-time or long-term support guarantee. See docs/privacy.md for data handling and docs/releasing.md for release gates.
